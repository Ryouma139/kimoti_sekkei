    SPEC ／ 設計メモ

    3つのノートを分けて、ホームで重ねる

    書く場所は気持ち・技術・学習の3つに分けます。ホームのカレンダーで、気分（アイコン）と学習時間（下のバー）を同じ日付に重ねて見せます。

    きもち日記

    1日1件。気分5段階＋自由文＋写真。気分がカードの色とアイコンを決める。

    テックノート

    プロジェクト（進捗・ステータス・技術スタック）と考え方メモ（ADR形式：背景／決定／理由）。

    まなびログ

    1日に何件でも。学習時間（分）とカテゴリを必須にして、自動で集計する。

    ページ構成

    /                    ホーム：気分ピッカー・きもちカレンダー・統計・最近の記録

/tech/               テックノート（プロジェクト／考え方メモのタブ）

/tech/notes/[slug]   考え方メモ（ADR）

/tags/[tag]          タグ別（3種類の記事を横断）

    データ設計（Astro Content Collections）

    // src/content.config.ts
const feel = defineCollection({
  loader: glob({ pattern: "**/*.md", base: "./src/content/feel" }),
  schema: z.object({
    date:    z.coerce.date(),
    mood:    z.enum(["great", "happy", "calm", "meh", "down"]),
    title:   z.string(),
    weather: z.string().optional(),
    photo:   z.string().optional(),
  }),
});

const tech = defineCollection({
  schema: z.object({
    type:     z.enum(["project", "note"]),
    title:    z.string(),
    status:   z.enum(["plan", "run", "done"]).optional(),
    progress: z.number().min(0).max(100).optional(),
    stack:    z.array(z.string()).default([]),
    repo:     z.string().url().optional(),
  }),
});

const learn = defineCollection({
  schema: z.object({
    date:     z.coerce.date(),
    minutes:  z.number(),                 // スタディタイム
    category: z.enum(["TypeScript", "AWS", "アルゴリズム", "設計"]),
    project:  z.string().optional(),      // tech の slug と紐づけ
    tags:     z.array(z.string()).default([]),
    source:   z.string().url().optional(),
  }),
});

    画面要素データ実装
    気分アイコンfeel.moodSVGコンポーネント MoodBlob.astro（5種類の表情と色）

    週グラフ・カテゴリ集計learn.minutes, learn.categoryビルド時に集計（ライブラリ不要。CSSのバーで描画）
    気分フィルター・サブタブ—小さなクライアントスクリプト（Astro Islands）
